## HUD Layout

```text
In-game HUD
┌────────────────────────────────────────────────────────────────────┐
│                                                      XP / Level     │
│                                           Passive + Perk list       │
│                                           cooldown/readiness text   │
│                                                                    │
│                                                                    │
│                         normal game view                           │
│                                                                    │
│                                                                    │
│                                                                    │
│                    native hotbar / ability controls                │
└────────────────────────────────────────────────────────────────────┘
```

- The MOTM XP/level readout and passive/perk ability list belong tucked into
  the top-right corner.
- The passive/perk list is text-first, not icon-first.
- Each passive/perk entry displays the ability name plus cooldown timer in
  seconds when applicable.
- Default ready state: white text with black outline, 100% opacity.
- Cooldown state: name and timer at about 60% opacity.
- Active/duration state: ability name becomes light green with black outline
  and temporary bold text; timer remains white with black outline and normal
  weight at 100% opacity.
- Bottom text must stay close to the normal health/hotbar region and must not
  include class titles such as "The Earthen Guardian".
- Resource UI is removed. Do not show Hydro Waterskin, water bars, soul bars,
  class-resource strips, or ability resource costs.
- Terra class passives must not apply external player/item tint visuals.

## Spellbook Shape

```text
Player Spellbook
┌──────────────────────────────────────────────────────────────┐
│ Tabs: Class │ Styles + Abilities │ Perks │ Stats             │
├──────────────────────────────────────────────────────────────┤
│ Class tab: collapsible class descriptions + passive effects  │
│ Styles tab: equipped style in green; ability descriptions    │
│ Perks tab: token count, collapsible perk descriptions        │
│ Stats tab: stat point redemption and current percent buffs   │
└──────────────────────────────────────────────────────────────┘

Dev/Test Spellbook
┌──────────────────────────────────────────────────────────────┐
│ Player tabs plus test-only class/style controls              │
└──────────────────────────────────────────────────────────────┘
```

- No story tabs belong in the spellbook.
- Do not show Journey, Codex, Journal, Grimoire, lore, quests, world-story
  sections, or reaction glossary tabs.
- The normal player spellbook must let the player view class, style, active
  abilities, perks, and stats.
- The dev/test spellbook may add controls to change class/style for testing,
  but those controls must not become the default player experience.
- Class info uses collapsible names/descriptions for the four classes and their
  passive abilities.
- Style info uses collapsible names/descriptions; the currently equipped style
  name is green.
- Ability descriptions must include current runtime behavior: cooldowns,
  durations, effects, function, and control expectations.
- Perk tab shows `Token Count: N`.
- Perk names/descriptions are collapsible.
- Selected perks have green names.
- Choosing a perk is a two-step confirmation: click one perk name, then show an
  accept button at the top of the perk tab.
- Stats tab uses stat points from level-ups. Click a stat name, then show an
  accept button at the top. Selected stat text turns green and the stat buff
  list below shows current percent contribution.
- Stat options are displayed as a compact two-row sorted list of possible stat
  buffs with the current percentage next to each.

## Startup Selection Flow

```text
New player joins
  └─▶ grant spellbook
      └─▶ open startup UI
          ├─▶ choose class
          │   ├─ list four classes
          │   ├─ click class to read description + passives
          │   └─ accept with Choose button
          └─▶ choose style
              ├─ list styles for selected class
              ├─ click style to read ability descriptions
              └─ accept, close UI, release movement
```

- New players receive the spellbook immediately.
- The startup UI opens before normal play when no class/style has been chosen.
- Player is invincible during the startup UI so they cannot die while making
  selections.
- After style acceptance, close the UI and allow normal movement.
